# Verum Omnis Assets

This directory contains visual assets for the Verum Omnis forensic engine.

## Logos

The `logos/` directory contains official Verum Omnis branding assets:

| File | Description |
|------|-------------|
| `main-logo.png` | Primary Verum Omnis logo |
| `logo-2.png` | Secondary logo variant |
| `logo-3.png` | Alternative logo variant |

### Usage

These logos should be used for:
- Application branding and splash screens
- PDF report watermarks (as specified in `verum-constitution.json`)
- Documentation and promotional materials

### Guidelines

Per the Verum Omnis constitution (`verum-constitution.json`):
- Use `main-logo.png` centered as the watermark on forensic PDF reports
- Maintain logo integrity - do not modify or distort the logos
- Use appropriate logo variant based on context and background
