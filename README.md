# Verum Omnis Forensic Engine

A stateless, offline-first forensic evidence processing engine built on constitutional governance principles.

## Overview

Verum Omnis is a forensic engine that cryptographically seals evidence and generates AI-readable reports for legal consultation. All processing is performed locally and offline, ensuring data privacy and security.

## Core Principles

The engine operates under the constitutional governance layer defined in `verum-constitution.json`:

1. **Truth**: Prioritize factual accuracy and verifiable evidence
2. **Fairness**: Protect vulnerable parties and expose coercion
3. **Human Rights**: Uphold dignity, equality, and procedural fairness
4. **Non-Extraction**: No sensitive data transmission or logging
5. **Human Authority**: AI assists but never overrides human judgment
6. **Integrity**: No manipulation, bias, or narrative distortion
7. **Independence**: No external influence on outputs

## Technical Standards

- **Cryptographic Hash**: SHA-512
- **PDF Standard**: PDF 1.7
- **Security**: Offline-first, stateless, airgap-ready
- **Output**: Cryptographically sealed, machine and human readable
